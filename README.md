## 검증 과정에서 발견 및 수정한 파서 버그
실제 지마켓 상품명은 처음 예상보다 훨씬 다양한 표기를 쓰고 있어, 실데이터 검증 중 다음 버그들을 발견해 고쳤습니다:

1. **번들 상품 오계산**: "펩시 210ml 30캔 + 사이다 210ml 30캔"처럼 `+`로 서로 다른 상품을 묶은 표기를 모든 토큰을 무조건 곱해버려 완전히 틀린 값을 냄 → 세그먼트별로 분리 계산 후 합산
2. **공백 없는 배수 표기 미인식**: "210mlx30캔"에서 단위 뒤 x를 숫자 접두어로 오인해 매칭 실패
3. **PET 단위 누락**: "1.25L x 12PET" 같은 음료 실무 표기
4. **길이 단위 부재**: 화장지/키친타월류는 "30M 30롤"(길이 x 롤 수)이 핵심 표기인데 길이 단위(m/cm)가 아예 없어서 "롤당 가격"으로 잘못 비교됨 → 길이 카테고리 추가, 1m당 가격으로 정규화
5. **곱셈 폭발(총합 재진술 문구)**: "6000매 ... 100매 60팩 ... 6000매"처럼 상품명 안에 총합을 재확인하는 문구가 섞여 있으면 전부 곱해져 천문학적 숫자가 나옴 → 토큰 클러스터링 + "누적곱과 값이 같으면 재진술로 간주해 제외" 로직으로 방지
6. **"총" 라벨의 이중적 의미**: "총32개"가 앞선 값들의 재진술인 경우와, 그 자체가 유일한 정보인 경우(예: "1팩 총 30롤")를 구분해 처리
7. **괄호가 유일한 정보를 담은 경우**: "(46매x12팩)상품명..." 처럼 수량 정보가 괄호 안에만 있으면, 괄호를 제거하는 전처리 때문에 파싱 실패 → 괄호 제거 후 실패하면 원본으로 재시도하는 폴백 추가
8. **"평량"(종이 두께 스펙) 오인식**: "75g 고평량 물티슈 ... 70매 10팩"에서 75g은 총 중량이 아니라 재질 스펙인데 무게로 오인해 완전히 틀린 단가가 나옴 → "평량" 키워드 근처의 무게 토큰은 제외

## 알려진 한계 (Known limitations)
- "24+6롤"(24개+보너스6개=30개) 처럼 보너스 수량을 `+`로 표기하는 경우, 번들 상품 구분용 `+` 분리 로직과 충돌해 파싱 실패할 수 있음 (152개 중 1건 발생, 낮은 빈도라 우선순위 낮음)
- 상품명 자체에 수량 정보가 전혀 없는 경우(브랜드/디자인 설명만 있는 경우)는 원천적으로 파싱 불가 → "단위 파싱 불가" 배지로 명시적으로 표시됨

## 구조
```
manifest.json
src/
  parser/unitParser.js     # 텍스트 -> 단위/수량 파싱, 단위가격 계산 (Node/브라우저 겸용)
  content/gmarketSearch.js # 지마켓 검색 결과 페이지에 배지 삽입 (content script)
  styles/badge.css         # 배지 스타일
tests/
  unitParser.test.js       # 파서 유닛 테스트 (node tests/unitParser.test.js 로 실행)
```

## 파서가 지원하는 표기
- `500ml`, `1.5L`, `1kg`, `210g` 등 단일 용량/무게
- `500ml x 20개`, `355ml 24캔`, `2L 6개입`, `210g x 12개` 등 용량 x 개수 조합
- `100매 x 3팩`, `12자루` 등 개수만 있는 상품(권/자루/매/입 등)
- `30M 30롤` 등 길이(m) x 개수 조합 (화장지/키친타월류)
- `A상품 + B상품` 형태의 번들 상품 (세그먼트별 계산 후 합산)
- 계산 결과는 100ml당, 100g당, 1m당, 개당 가격으로 정규화됨

테스트 실행:
```
node tests/unitParser.test.js
```

## 크롬에 로드해서 테스트하는 방법
1. `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 프로젝트 폴더(`gmarket-unitprice-ext`) 선택
5. 지마켓에서 검색 → 상품 카드에 단위가격 배지가 붙고, 최저가 카드에 주황 테두리가 표시되는지 확인
   - 콘솔(F12)에서 에러가 없는지, 배지가 안 붙으면 원인 확인 필요 (지마켓이 DOM 구조를 바꿨을 가능성)
